# 真人試用與排練方案

準備日期：2026-10-03。這是待執行方案，**沒有招募、實測結果或受訪者引述**。

## 試用（每人約 15 分鐘）

至少兩名真实参与者，分别熟悉管理员和受训前线角色；角色招募不能冒充已招到的人。先取得同意，說明實驗資料、非安全認證及不測試真火／車輛。自願參與，可随时停止；不收集姓名、VIN、車牌、具體車位或敏感事故信息。錄音／錄屏须另行同意，避免拍到私人通知與密鑰。

主持人先给兩分钟簡介，再观察，不提示每一步。使用實測 NASA 記錄，不修改溫度制造警報。

| 任務 | 觀察重点 | 成功判断 |
|---|---|---|
| 找到 B0005 最新循環與來源 | 查來源和歷史／即時区别 | 正確说出是歷史实验电芯 |
| 解释熱狀態與容量 review | 有否把維護當火警 | 不声称已发火警或電池安全 |
| 在 3D 看最熱測點與灰色区域 | 是否误会為整包实测 | 說出未測區域／未知位置 |
| 交接到工作台並匯出 | 前後同一测点、格式与耗时 | 保存正确來源与量測 |
| 打開前線模式／官方搜尋 | 手机可读性、来源范围 | 找到官方指引，不把它当 AI 诊断 |
| 查看未配置／断连状态 | 是否感到错误地“正常” | 知道没有实时车况和 AI 結果 |

结束三分钟問：最難理解之处、實際交接需要甚麼、裝置／語言／網路障碍。不要誘導「是不是更安全」等肯定回答。

記錄欄位：匿名參與代號、真实角色描述（可选）、同意狀態、裝置／語言、每項開始與結束时间、完成／未完成、錯误原话（取得同意）、主持人介入次數、待改善點。保留原始記錄和样本数，不自动生成滿意分。

优先修复：把容量維護當火警、把灰色當零温度、把历史資料當车况、把密钥检测當模型驗證。其他問題按觀察頻次与任务影响排序。
