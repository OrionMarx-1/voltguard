- 全宽琥珀／红色状态条接入仿真规则；正常隐藏状态条。标题、模式、图内标记、区域名称、规则结果均明确为仿真。3D 渲染计数把仿真区域和量测区域分开。
- 「使用 NASA 记录」恢复之前的真实电芯／循環／量测点；刷新退出仿真。没有覆盖实际 NASA 数据或以前的会话选择。
- 复用 2D／3D 渲染与固定 20–80°C 色阶，不改真实量测色阶来让正常场景显得「全绿」。色彩不代表火灾概率或安全认证。
